# 파트 4. 검사기 (규칙)

### Q43. 규칙 검사기는 어떻게 일하나요?
🟢 ① 형태소 태그·정규식으로 **의심 자리 찾기** → ② **함정(오탐 자리) 거르기** → ③ 지적 만들기. 코드의 80%는 ②입니다.
📎 책 6.0

### Q44. 받침이 있는지 어떻게 아나요?
🟢 **산수**입니다. `(글자번호 − 44032) % 28`이 받침 번호이고 0이면 받침 없음.
📎 책 2장 `hangul.py`

### Q45. 왜 28로 나누나요?
🟢 한글은 `초성19 × 중성21 × 종성28 = 11,172자`가 번호순으로 놓여 있고, 종성이 가장 안쪽 단위라 28로 나눈 나머지가 종성입니다.
📎 책 2.2

### Q46. 조사 `을/를`은 어떻게 고르나요?
🟢 앞말 마지막 글자 받침이 **없으면 를/는/가/와/로, 있으면 을/은/이/과/으로**. `ㄹ` 받침은 `로`가 예외입니다.
📎 `josa.py`

### Q47. 틀린 조사를 형태소 분석기가 못 찾지 않나요?
🟢 맞습니다. `학교을`의 `을`을 Kiwi는 **명사로 읽습니다**. 그래서 "조사 태그"가 아니라 **명사 바로 다음 글자**를 직접 봅니다.
📎 책 3.6

### Q48. `가수이다`를 `가수가다`로 잘못 고치지 않나요?
🟢 안 고칩니다. 진짜 조사 뒤에는 공백·부호·끝이 와야 하는데 `이` 뒤에 `다`가 이어지므로 조사가 아니라고 봅니다.
📎 `_particle_boundary_ok`

### Q49. `뭔가`·`건가`는요?
🟢 어미 `-ㄴ가`가 앞 음절에 **융합**된 것(종성 자모로 시작)이라 조사로 안 봅니다.
📎 `_ending_tail_positions`, 구어 정문 오탐 25건 중 17건이 이 부류

### Q50. 숫자 뒤 조사(`3를`)는요?
🟢 **판단하지 않습니다.** "삼"으로 읽는지 "쓰리"로 읽는지 몰라서, 켜 보니 오탐이 3배가 됐기 때문입니다.
📎 `josa.py` 주석 (0.05% → 0.15%)

### Q51. 사전 규칙은 몇 개고 어떻게 만드나요?
🟢 **474개** 정규식. 앞뒤 문맥을 넣어 구분합니다(`카드로 결재`→`결제`, `서류를 결재`는 그대로).
📎 `dict_rules.json`

### Q52. 사전 규칙이 틀린 적은?
🟢 있습니다. **정문을 고치려던 규칙 9개**를 찾았습니다(예: 인물 `성희안`을 `성희한`으로). 경계 조건을 달거나 low로 내렸습니다.
📎 DESIGN 1.10-c

### Q53. 율/률은?
🟢 앞 글자가 **모음이나 ㄴ 받침이면 `율`**, 아니면 `률`. 단어 끝은 접미사 태그로, 단어 속(`자률신경`)은 언어모델 점수로 확인합니다.
📎 책 6.3

### Q54. 의존명사 띄어쓰기는?
🟢 **관형사형 어미(ETM) 뒤의 의존명사**(것·수·뿐·줄…)만 확정해 띄웁니다. `먹을것`→`먹을 것`.
📎 책 6.5

### Q55. `-ㄹ걸`, `-는데`, `갈릴리`는 왜 안 고치나요?
🟢 각각 종결어미 / 연결어미 / 지명이기 때문입니다. 단어마다 **틀(frame)을 확인**하고 맞을 때만 고칩니다.
📎 `dependent_noun.py`

### Q56. 간접 인용 `온다라고`는?
🟢 종결어미 바로 뒤에 `라고`가 붙으면 겹침이라 `온다고`로. 사이에 따옴표가 있으면(직접 인용) 건드리지 않습니다.
📎 `quotation.py`

### Q57. 물음표는 어떻게 아나요?
🟢 **의문 어미 + 같은 문장 안의 의문사**(어디·몇·왜…)가 둘 다 있을 때만 `.`→`?`. 그래서 `나야.`는 그대로입니다.
📎 `question_mark.py`

### Q58. 사물 존대(`커피 나오셨습니다`)는요?
🟢 **사물 목록**(animacy.json)에 있는 명사가 주어일 때만 고칩니다. 사람인지 사물인지는 어떤 태그에도 없어서 목록을 씁니다.
📎 `honorific.py`

### Q59. `에게/에` 구분은?
🟢 유정물/무정물 **명사 목록** + `에`는 **수여 동사가 있는 문장일 때만**. `에`의 다른 쓰임(장소 등)이 너무 많아서 교정 쪽을 허가제로 했습니다.
📎 `animacy_particle.py`

### Q60. 시제 호응은?
🟢 시간 부사(어제·내일…)와 서술어 시제가 **정면 모순일 때만**(과거 부사 + 현재형 등). 역사적 현재는 건드리지 않습니다.
📎 `tense.py`

### Q61. `전혀 다르다`는 왜 안 잡나요?
🟢 `다르다·새롭다` 같은 **허용 서술어**가 있으면 정문입니다. 부정 호응 규칙의 예외 목록입니다.
📎 `negative_polarity.py`

### Q62. `-시키다`는 항상 틀린 건가요?
🟢 아닙니다. `교육시키다`처럼 `-하다`가 이미 타동사인 **명사 목록**일 때만 군더더기로 봅니다(`변화시키다`는 필요).
📎 `redundant_causative.py`

### Q63. 이중 피동은 어떻게 잡나요?
🟢 **형태소 배열**을 봅니다: 피동사 어간 + `-어` + `지(VX)`. 어간을 고치고 `kiwi.join`으로 활용형을 되살려 `잊혀졌다→잊혔다`.
📎 책 6.15

### Q64. 왜 문자열 규칙 대신 형태소 규칙인가요?
🟢 문자열 규칙은 활용형을 하나씩 적어야 해서 `잊혀졌다`, `보여집니다`, `닫혀진`을 전부 놓쳤습니다(탐침 11/11 미탐).
📎 `morph_rules.py` 설명

### Q65. 문체 일관성은 어떻게 판정하나요?
🟢 문장마다 종결어미로 문체를 분류하고 **다수 문체가 60% 이상**이면 소수 문체 문장을 지적합니다. 반말↔존댓말일 때만 고쳐 쓰기를 제안합니다.
📎 `consistency.py`

### Q66. 띄어쓰기는 어떻게 검사하나요?
🟢 네 갈래: ① BiGRU 태거(점선) ② Kiwi가 지운 공백(medium) ③④ 규칙 30여 개(high).
📎 책 10장

### Q67. 띄어쓰기 자동 교정은 모델이 하나요?
🟢 **아니요.** 모델 단독으로는 점선(low)까지만. 자동 교정은 **규칙이 정한 자리**에서만 합니다.
📎 `MODEL_NEVER_AUTOFIXES = True`

### Q68. 왜 띄어쓰기에서 모델을 믿지 않나요?
🟢 태거는 경계 하나하나 F1 0.945지만 **문장 전체를 다 맞히는 비율은 44.8%**라서 그대로 자동 교정하면 안 됩니다.
📎 `spacing_tagger.py`

### Q69. 띄어쓰기 "허용"이 뭔가요?
🟢 규범이 둘 다 허용하는 표기(보조용언 붙여쓰기 등)는 **침묵**합니다. 필수 / 권장 / 허용 3단계, 애매하면 허용으로 보냅니다.
📎 `spacing_tiers.py`

### Q70. `못하다`는 왜 안 고치나요?
🟢 한 단어로 굳은 말이고, 위키 13건이 **전부 정문**이었습니다.
📎 `_NEG_LEXICALIZED`

### Q71. 오타(`매읽`)는 어떻게 잡나요?
🟢 사전에 없고 Kiwi도 못 읽은 2~3음절 어절을, **키 한 번 실수**로 닿는 흔한 말(`매일`)로 바꿉니다. 대부분 점선입니다.
📎 책 9장

### Q72. 키보드 실수를 어떻게 계산하나요?
🟢 글자를 키 입력열로 풀어(`ㄺ`=`ㄹ`+`ㄱ`) **한 키 더/덜/이웃 키**인지 봅니다. `구촌→구몬`은 키보드 양 끝이라 제외.
📎 `keystrokes.py`

### Q73. 이상탐지는 뭔가요?
🟢 사전에 없고 글자 이음이 **한국어답지 않은** 어절에 점선만 긋습니다. 고칠 말은 없습니다.
📎 `anomaly.py`, 임계값 11.25

### Q74. 이상탐지는 왜 평균이 아니라 최댓값인가요?
🟢 긴 어절의 이상한 이음매 한 곳을 평균이 희석하기 때문입니다(평균은 오문이 정문보다 낮게 나왔음).
📎 `anomaly.py` 설명
