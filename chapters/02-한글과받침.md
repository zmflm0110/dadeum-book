# 2장. 한글이 컴퓨터 안에서 어떻게 생겼나

다듬의 조사 검사(`을/를`, `이/가`…)는 한 가지 계산에 기대고 있습니다.
**"이 글자에 받침이 있는가?"를 산수로 알아내는 것**입니다. 이 장은 그 산수를 처음부터 설명합니다.

## 2.1 컴퓨터는 글자를 번호로 저장한다

컴퓨터 안에는 글자가 없고 **번호**만 있습니다. 글자마다 번호를 하나씩 정해 둔 표를 **유니코드**라고 합니다.
파이썬에서 `ord("가")`는 글자의 번호를, `chr(번호)`는 번호의 글자를 돌려줍니다.

```python
ord("가")   # 44032  (16진수로 0xAC00)
ord("힣")   # 55203  (16진수로 0xD7A3)
chr(44032)  # '가'
```

완성된 한글 글자(가, 각, 간, …, 힣)는 **44032번부터 55203번까지 11,172개**가 빈틈없이 줄지어 있습니다.

## 2.2 11,172는 어디서 나왔나

한글 한 글자는 세 부분으로 이루어집니다.

| 부분 | 이름 | 가짓수 | 예 (`학`) |
|---|---|---|---|
| 첫소리 | 초성 | 19 | ㅎ |
| 가운뎃소리 | 중성 | 21 | ㅏ |
| 끝소리(받침) | 종성 | 28 (받침 없음 포함) | ㄱ |

19 × 21 × 28 = **11,172**. 모든 조합이 번호표에 하나씩 들어 있는 것입니다.

번호는 이 순서로 매겨져 있습니다.

```
(글자 번호 − 44032) = (초성 번호 × 21 + 중성 번호) × 28 + 종성 번호
```

사전에서 "초성 → 중성 → 종성" 순으로 정렬한 것과 같습니다. 같은 초성, 같은 중성인 글자들이 종성 순서대로 28개씩 붙어 있습니다.

```
가(종성 0, 받침 없음) 각(1: ㄱ) 갂(2: ㄲ) 갃(3: ㄳ) 간(4: ㄴ) ... 갛(27: ㅎ)
```

## 2.3 받침 번호를 꺼내는 한 줄

위 식에서 **28로 나눈 나머지가 종성 번호**입니다.

```python
받침번호 = (ord(글자) - 0xAC00) % 28
```

`%`는 나머지입니다. 실제로 계산해 보았습니다.

| 글자 | 번호 | 번호 − 44032 | % 28 | 뜻 |
|---|---|---|---|---|
| 가 | 44032 | 0 | **0** | 받침 없음 |
| 각 | 44033 | 1 | **1** | ㄱ |
| 힣 | 55203 | 11171 | **27** | ㅎ |
| 교 | 44368 | 336 | **0** | 받침 없음 |
| 학 | 54617 | … | **1** | ㄱ |
| 을 | 51012 | … | **8** | ㄹ |

종성 번호표는 이렇습니다(0은 받침 없음).

```
0:없음 1:ㄱ 2:ㄲ 3:ㄳ 4:ㄴ 5:ㄵ 6:ㄶ 7:ㄷ 8:ㄹ 9:ㄺ 10:ㄻ 11:ㄼ 12:ㄽ 13:ㄾ 14:ㄿ
15:ㅀ 16:ㅁ 17:ㅂ 18:ㅄ 19:ㅅ 20:ㅆ 21:ㅇ 22:ㅈ 23:ㅊ 24:ㅋ 25:ㅌ 26:ㅍ 27:ㅎ
```

## 2.4 실제 코드: `app/hangul.py`

이 파일 전체가 38줄입니다. 핵심만 옮깁니다.

```python
HANGUL_BASE = 0xAC00      # '가'
HANGUL_LAST = 0xD7A3      # '힣'
JONGSEONG_COUNT = 28      # 받침 가짓수 (0 = 받침 없음)

NO_BATCHIM_INDEX = 0
NIEUN_INDEX = 4           # ㄴ - 율/률 예외
RIEUL_INDEX = 8           # ㄹ - 로/으로 예외

def is_hangul_syllable(ch):
    return len(ch) == 1 and HANGUL_BASE <= ord(ch) <= HANGUL_LAST

def final_index(ch):
    if not is_hangul_syllable(ch):
        return None
    return (ord(ch) - HANGUL_BASE) % JONGSEONG_COUNT
```

읽는 법:

1. `is_hangul_syllable`: "글자 하나이면서 번호가 44032~55203 사이인가?" 한글 완성 글자인지 확인합니다.
2. `final_index`: 한글이 아니면 `None`(모른다)을 돌려주고, 한글이면 받침 번호를 돌려줍니다.

**왜 한글이 아닐 때 `None`인가?** 숫자·영문·기호는 받침이 있는지 알 수 없기 때문입니다.
이 엔진의 원칙은 "모르면 가만히 있기"이고, `None`이 그 신호입니다. 부르는 쪽은 `None`을 받으면 판단을 포기합니다.

## 2.5 이걸로 조사를 어떻게 고르나

조사는 앞말의 마지막 글자 받침에 따라 짝이 정해집니다.

| 받침 없음(0) | 받침 있음 |
|---|---|
| 를 | 을 |
| 는 | 은 |
| 가 | 이 |
| 와 | 과 |
| 로 | 으로 |

`학교을`의 마지막 글자는 `교`, 받침 번호는 0, 따라서 **`를`이어야 합니다**. 그런데 `을`이 적혀 있으니 오류입니다.

`로/으로`만 예외가 하나 있습니다. **ㄹ 받침(8번)은 받침 없는 것처럼 `로`를 씁니다.** `물로`, `서울로`가 그렇습니다.
코드에서는 `rieul_exception=True`일 때 `idx == RIEUL_INDEX`도 "받침 없음"으로 취급합니다.

```python
def _expected_particle(host_last_char, no_batchim, has_batchim, rieul_exception=False):
    idx = _final_index(host_last_char)
    if idx is None:
        return None           # 숫자/영문/기호: 모른다
    no_batchim_case = idx == NO_BATCHIM_INDEX or (rieul_exception and idx == RIEUL_INDEX)
    return no_batchim if no_batchim_case else has_batchim
```

## 2.6 율/률도 같은 계산

`합격률`, `비율`: 모음이나 ㄴ 받침 뒤에는 `율`, 그 밖에는 `률`을 씁니다(맞춤법 제11항).
`NIEUN_INDEX = 4`가 이 규칙의 예외를 위한 상수입니다. 같은 `final_index` 하나로 두 규칙을 처리합니다.

## 2.7 숫자는 왜 판단하지 않는가

`3을`일까 `3를`일까? 3을 "삼"(ㅁ 받침)으로 읽으면 `을`, "쓰리"로 읽으면 `를`입니다.
코드에는 숫자를 읽는 소리로 푸는 표(`_DIGIT_FINAL`)가 만들어져 있는데 **실제로 쓰지 않습니다.**

```
_DIGIT_FINAL = {"0": 21, "1": 8, "2": 0, "3": 16, ...}  # 영/일/이/삼/…
```

한 번 켜 보고 실측했더니 재현율은 0.850 → 0.866으로 올랐지만 **정문 오탐이 0.05% → 0.15%로 3배**가 됐습니다.
원인은 읽는 법이 하나가 아니라는 것입니다.

| 문장 | 읽는 법 | 현재 표기가 맞는가 |
|---|---|---|
| 언리얼 엔진 3**를** | "쓰리" | 맞음 (오류 아님) |
| 충정로 3**가** | "가"(街)는 조사가 아니라 지명 단위 | 오류 아님 |
| 여우원숭이 5**과** | "과"(科)는 분류 단위 | 오류 아님 |

그래서 결정은 "문맥 신호가 생기기 전에는 숫자 뒤 조사를 판단하지 않는다"였고, 읽기 유틸은 나중을 위해 남겨 두었습니다.
**여기서 배울 것:** 맞출 수 있는 걸 일부러 안 맞춘 것입니다. 이 프로젝트에서 "침묵"은 실패가 아니라 선택입니다.

## 2.8 어절 경계 찾기

`hangul.py`에는 하나가 더 있습니다.

```python
def eojeol_bounds(text, i):
    """i번 글자가 속한, 공백으로 나뉜 한 덩어리의 [시작, 끝)."""
    start = i
    while start > 0 and not text[start - 1].isspace():
        start -= 1
    end = i
    while end < len(text) and not text[end].isspace():
        end += 1
    return start, end
```

`i`에서 왼쪽으로 공백이 나올 때까지, 오른쪽으로 공백이 나올 때까지 걸어갑니다. `while`은 "조건이 참인 동안 반복"입니다.

```
text = "나는 학교를 갔다",  i = 5 (교)
왼쪽으로: 4(학) → 3(공백) 멈춤 → start = 4
오른쪽으로: 5 → 6(를) → 7(공백) 멈춤 → end = 7
결과 (4, 7) = "학교를"
```
