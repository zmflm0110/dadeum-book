# 다듬(DaDeum) 완전정복

한국어 맞춤법 교정 엔진 [다듬](https://github.com/zmflm0110/dadeum)의 코드를, 코드를 처음 배우는 사람도
끝까지 따라가면 전부 이해하게 되도록 풀어 쓴 교재입니다.

| 읽는 사람 | 파일 | 분량 |
|---|---|---|
| 시간이 없는 사람 | `다듬-쉽게읽기.pdf` | 한 주제 한 쪽, 16쪽 |
| 단계별로 깊게 | `다듬-5단계설명.pdf` | 초등학생 → 전문가 |
| 질문에 답해야 하는 사람 | `다듬-질의응답.pdf` | 질문 176개 + 치트시트 |
| 코드를 이해하고 싶은 사람 | `다듬-완전정복.pdf` | 0~14장 교재 |

원본은 `easy/`, `qa/`, `chapters/`(Markdown). 다시 만들기: `./build-easy.sh` `./build-qa.sh` `./build.sh` (pandoc + Chrome).
